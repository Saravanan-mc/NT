## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.0.0 or higher) and `npm` installed.

### Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd ntarchitecture-main
npm install
```

### Development Server

Start the local development server with hot module replacement (HMR):

```bash
npm run dev
```

The application will run at `http://localhost:5173`.

### Production Build

Compile TypeScript and build the optimized production assets:

```bash
npm run build
```

Production output will be generated in the `dist/` directory.

### Preview Build

Preview the production build locally:

```bash
npm run preview
```
